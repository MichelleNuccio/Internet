# Published runtime assets

This folder contains the browser-ready subset of the research materials used by
the public site. The original source folders can remain local:

- `piano-01/` contains the cable records, coastline, selected notebook figures,
  and spreadsheet used by the cable floor and desktop.
- `piano-03/` contains the storyboard, its records, preview maps, and linked
  map PDFs used by the IPv4 floor.

When those source materials change, refresh these runtime copies and keep their
relative paths intact. The website does not load files from the repository's
`material/` or `web/data/` folders.
